# PocketSmart

A personal budget and recommendation dashboard. PocketSmart gives a quick view of income, spending, category budgets, recent transactions, and a small, actionable spending insight.

## Run locally

Open `index.html` in a browser, or serve the project directory:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Overview of monthly income, spending, and remaining balance.
- Spending breakdown and category budget progress.
- Add income or expense transactions and search activity.
- Adjust category budgets and see updated recommendations.
- Saves changes in browser local storage; no account or backend required.

The dashboard starts with sample October 2026 data. Reset its sample state by clearing this site's local storage.
